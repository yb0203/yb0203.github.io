# 6E. Showcase Demo Product Lifecycle & FDE Handoff Framework

## ⚡ TL;DR
- Defines the end-to-end creation, team structure, 21-day sprint timeline, build order, and sales conversion handoff for the **Showcase Demo Product**.
- The showcase demo is built on top of **Lyzr's Agent Builder Platform** (handling all agent primitives: RAG, tool schemas, guardrails, LLM routers, governance, tracing) and a modern Next.js frontend.
- It serves as the primary pre-sales vehicle to win C-suite banking executive meetings. Upon deal signing, Forward-Deployed Engineers (FDEs) clone the demo codebase and customize it inside the client's private VPC.

## 📖 Full Detail

### 1. Architectural Architecture & Stack
* **AI Agent Backend**: Lyzr Agent Builder Platform (Python SDK / REST APIs), Lyzr RAG Core, Lyzr Guardrails & Tracing.
* **Showcase Frontend**: Next.js (App Router), React, TailwindCSS, Lucide Icons, Framer Motion, `react-pdf` / `pdfjs` (bounding-box coordinate rendering engine).
* **State Management & Offline Feed**: Zustand / React Query with fallback mock scenario feeds for offline sales execution.

### 2. Prioritized Component Build Order
1. **Grounded Dual-Pane Citation Viewer**: Left PDF viewer + right agent panel with clickable bounding-box coordinate overlays on original PDF pages.
2. **"Approve-Before-Act" Interactive Action Cards**: Action cards generated by Lyzr agents featuring confidence scores, cited evidence, and `[ Approve ]`, `[ Edit & Approve ]`, `[ Reject & Override ]` controls.
3. **Commercial Credit Spreading & DSCR Board**: Ingests balance sheet PDFs, calculates DSCR ($\ge 1.25\times$), LTV, and debt yield metrics.
4. **Schedule B Title Vetting & Exception Matrix**: Automatically extracts Schedule B risks (taxes, prior mortgages, easements) and generates a Title Clearance Checklist.
5. **Court Scout & PACER Foreclosure Live Feed**: Real-time event ticker simulating PACER court docket syncs, statutory FDCPA cure countdown timers, and default letter previews.

### 3. Team Structure (4-Person Pod)
* **1x Lead Full-Stack / Frontend Engineer**: Next.js UI, bounding-box PDF visualizer, animations, dark mode aesthetics.
* **1x Agentic AI Integrator**: Configures Lyzr Agent primitives, RAG vector stores, prompt guardrails, `zod` schemas, and API client hooks.
* **1x Banking Legal Ops Product Specialist**: Curates realistic US bank PDF test dossiers (Title commitments, 10-Ks, PACER files) and designs sales storyboards.
* **1x Solutions Architect / FDE Lead**: Packages repo structure, writes `clone-client.sh`, and manages client VPC environment isolation.

### 4. 21-Day Sprint Timeline (3-Week Execution Plan)
* **Week 1 (Days 1–7) - Core Shell & Lyzr Wiring**: Set up Next.js UI shell, configure Lyzr agents (Court Scout, Title Vetting, Financial Spreading), and define test dossiers & `zod` schemas.
* **Week 2 (Days 8–14) - Core Interactive Features**: Build dual-pane PDF bounding-box citation viewer, interactive proposal cards, DSCR spreading board, and Schedule B title matrix.
* **Week 3 (Days 15–21) - Sales Polish, Storyboarding & FDE Templatization**: Add UI micro-animations, offline sales fallback feeds, finalize sales pitch script, freeze showcase demo, and write FDE cloning script (`/scripts/clone-client.sh`).

### 5. FDE Client Conversion & Customization Journey
```
[ Sales Pitch (Showcase Demo) ] ──► [ Client Signs Paid PoC ]
                                             │
                                             ▼
                      [ FDE Runs `scripts/clone-client.sh --name=TargetBank` ]
                                             │
                                             ▼
                      [ FDE Steps into Client Private VPC Infrastructure ]:
                      1. Provision Client-Isolated Lyzr Agent Workspace ID
                      2. Swap S3/Blob Storage Keys for Real Bank PDF Ingestion
                      3. Configure Bank Single Sign-On (SSO / Okta)
                      4. Deploy Containerized App to Client AWS/Azure VPC
```
