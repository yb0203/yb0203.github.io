# Course Syllabus: Applied AI Agents for Product Managers

*   **Format:** 6 sessions (2 hours each).
*   **Pedagogical Target:** 30% Concepts & Taxonomy, 70% PM Application, Strategy & Hands-on Work.
*   **Goal:** Learn how to design, prototype, evaluate, and productize AI Agents without writing code.

## Session Objectives

### [Session 1: Anatomy & Taxonomy of AI Agents](file:///Users/hkc/Documents/job-prep/ai%20agents%20course/sessions/session_1.md)
*   **Objective:** Understand what makes a system "agentic" vs. a regular chatbot. Learn the five cognitive pillars (Brain, Planning, Memory, Tools, Collaboration).
*   **PM Deliverable:** Select an agentic feature and complete a Build vs. Buy Scorecard.

### [Session 2: Knowledge Augmentation & Memory (RAG)](file:///Users/hkc/Documents/job-prep/ai%20agents%20course/sessions/session_2.md)
*   **Objective:** Understand how agents store and retrieve knowledge. Ground agents using Retrieval-Augmented Generation (RAG) and manage short-term context.
*   **PM Deliverable:** Design a Claude Project seeded with internal knowledge documents and write a grounding strategy.

### [Session 3: Actions & Tool Calling (MCP & Execution)](file:///Users/hkc/Documents/job-prep/ai%20agents%20course/sessions/session_3.md)
*   **Objective:** Learn how agents execute actions using APIs and run sandboxed code. Demystify the Model Context Protocol (MCP) and function JSON schemas.
*   **PM Deliverable:** Write structured instructions telling an agent how and when to trigger a Google Sheets API tool call.

### [Session 4: Decomposition & Planning Loops](file:///Users/hkc/Documents/job-prep/ai%20agents%20course/sessions/session_4.md)
*   **Objective:** Understand reasoning loops (ReAct), goal decomposition, reflection, and self-correction.
*   **PM Deliverable:** Create an agent state machine flowchart mapping user instructions to planning sequences.

### [Session 5: Orchestrating Multi-Agent Collaboration](file:///Users/hkc/Documents/job-prep/ai%20agents%20course/sessions/session_5.md)
*   **Objective:** Learn when to split tasks into multiple specialized worker agents (e.g., researcher, editor) instead of a single generalist.
*   **PM Deliverable:** Map out a multi-agent system workflow showing handoffs, inputs, outputs, and human-in-the-loop gates.

### [Session 6: AI Evaluation & Quality Control (Evals)](file:///Users/hkc/Documents/job-prep/ai%20agents%20course/sessions/session_6.md)
*   **Objective:** Learn how PMs test and measure agent performance. Build "golden datasets" and use LLM-as-a-judge to evaluate agent reliability.
*   **PM Deliverable:** Build a comprehensive AI PRD and an Evaluation Matrix for their final course agent.
