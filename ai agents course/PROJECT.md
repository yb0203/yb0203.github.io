# Project: Applied AI Agents Course for Non-Developers (Aspiring PMs)

## Architecture
- Target Audience: Non-developers, Aspiring PMs.
- Pedagogical Split: 30% conceptual theory, 70% PM strategy/application.
- Taxonomy Focus: Brain/Reasoning, Planning, Memory/RAG, Tool Use, Collaboration/Multi-Agent.
- Delivery Model: 6 sessions, each with conceptual foundation, PM context, instructor setup/script, student hands-on exercise (zero-code web UI), and deliverables.
