# Job Prep & Application Pipeline Rules (3-Entity Model)

## 1. 3-Entity Domain Model & Schema Integrity
- **Companies (`tracker/companies.csv`)**: Primary accounts (`company_id`, `name`, `domain`, `tier`, `industry_vertical`, `hq_location`, `tech_stack_summary`, `target_leverage_hook`, `notes`).
- **Contacts (`tracker/contacts.csv`)**: Stakeholders and recruiters (`contact_id`, `company_id`, `full_name`, `role_title`, `channel`, `profile_url`, `email`, `phone`, `status`, `notes`).
- **Applications (`tracker/applications.csv`)**: Consolidated opportunity and interaction record (`app_id`, `company_id`, `primary_contact_id`, `role_title`, `track`, `stage`, `priority`, `date_added`, `last_contacted_date`, `next_followup_due`, `latest_interaction_type`, `interaction_history`, `next_action`, `tailored_resume_path`, `pitch_artifact_path`, `comp_target`, `notes`).

## 2. Integrity Enforcement
- Every application must reference a valid `company_id` in `companies.csv` and valid `primary_contact_id` in `contacts.csv`.
- Whenever CSV files are edited, run:
  ```bash
  python3 tracker/manage.py validate
  python3 tracker/manage.py export-kanban
  ```

## 3. Safe Email & Gmail API Protocol
- **Draft-First Policy**: All cold outreach or follow-ups generated by agents must be created in Gmail Drafts using `tracker/email_client.py --draft` or previewed with `--preview`.
- **No Direct Dispatch Without Approval**: Never execute `--send` without explicit human confirmation.
- **Auto-Sync Application State**: Drafting or sending an email automatically updates `last_contacted_date`, `next_followup_due` (default: 4 business days), `latest_interaction_type`, and appends to `interaction_history` in `tracker/applications.csv`.
